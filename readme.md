# Simulação de Fluido

Este projeto é uma simulação interativa de fluidos 2D construída com HTML5 Canvas, CSS e JavaScript.

O projeto cria a ilusão visual de água utilizando uma mecânica de molas. A superfície da água é dividida em centenas de colunas invisíveis que agem como molas conectadas, resultando em uma simulação leve, rápida e visualmente agradável.

- Clique em qualquer lugar do quadro para jogar bolinhas com tamanhos aleatórios.
- As bolinhas sofrem ação da gravidade, colidem entre si, e interagem com a água através de forças de empuxo e arrasto.
- Um botão permite criar uma onda ajustável no centro do fluido.
- Ajuste o comportamento do fluido com as propriedades de tensão, amortecimento e propagação.

Para executar, tenha os arquivos no mesmo diretório e abra o arquivo `index.html` na web.
